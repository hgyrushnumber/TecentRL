# 当前算法性能问题深度分析

## 核心问题：为什么分数难以提升？

经过深入分析，发现当前算法存在**5个致命问题**，严重阻碍性能提升。

---

## 问题1：奖励尺度严重失衡 ⚠️ **最严重**

### 现象
模型倾向于"苟活"而不去收集宝箱，或者盲目冲向宝箱被抓。

### 根本原因
奖励各项量级完全失衡：

| 奖励项 | 单步最大值 | 1000步累积 | 占比 |
|--------|-----------|-----------|------|
| 存活奖励 | 0.04 | ~40 | 48% |
| 宝箱收集 | 5.0 | 5~15 | 18% |
| 宝箱接近 | 1.0 | ~200 | 240% |
| 风险惩罚 | -0.45 | -50~-200 | 60% |
| 终局奖励 | 5.0 | 5.0 | 6% |

**问题：**
1. **宝箱接近奖励过高**（累积200 vs 宝箱收集仅5）：模型学会绕着宝箱转圈刷接近奖励，而不拾取
2. **存活奖励占比过高**（40分）：模型倾向于原地不动或无意义移动
3. **终局奖励微不足道**（5分 vs 累积200+分）：模型不在乎输赢

### 影响
- **奖励稀疏性被破坏**：密集奖励信号淹没了关键目标
- **策略偏差**：模型优化错误的目标（刷接近奖励而非收集宝箱）
- **收敛困难**：梯度方向被噪声主导

---

## 问题2：奖励信号噪声过大

### 现象
训练损失波动大，曲线震荡，难以收敛。

### 根本原因
奖励由11项组成，大部分是噪声：

```python
# 有效信号（稀疏、明确）
treasure_reward = 5.0          # 收集宝箱（关键目标）
final_reward = ±5.0            # 终局胜负（关键目标）

# 噪声信号（密集、模糊）
survive_reward = 0.02~0.04     # 每步都有，无指导意义
escape_reward = 0~0.15         # 触发条件复杂
risk_penalty = -0.15~-0.45     # 与距离强相关，冗余
milestone_reward = 0.02~0.10   # 每20步，无意义
treasure_proximity = 0~1.0     # 过强，副作用大
buff_reward = 0.2              # 稀疏但非核心
buff_proximity = 0~0.05        # 噪声
movement_reward = 0~0.03       # 无意义移动奖励
skill_reward = 0.02~0.15       # 滥用技能刷奖励
```

**问题：**
- 11项奖励 → 梯度方向混乱
- 密集噪声淹没了稀疏信号
- TD目标方差过大：`target = r + γ*V(s')`，r本身方差=100+

### 影响
- **训练不稳定**：损失震荡，难以收敛
- **学习效率低**：需要大量样本才能提取有效信号
- **PER失效**：TD误差大≠样本价值高，可能只是噪声

---

## 问题3：探索策略失效

### 现象
模型在安全区域反复震荡，不敢靠近宝箱。

### 根本原因
**SAC探索机制不适合稀疏奖励任务：**

1. **熵正则化误导**：
   ```python
   # 当前熵目标
   target_entropy = 0.75 * log(10) = 1.73
   
   # 问题：鼓励均匀探索，但任务需要定向探索
   ```
   - 游戏中大部分动作是无意义的（撞墙、原地转圈）
   - 均匀探索→80%时间在无效动作

2. **自动α调优不当**：
   ```python
   alpha_loss = α * (H[π] - target_entropy)
   ```
   - 初期α过大→策略接近随机→学不到任何东西
   - 后期α衰减→探索不足→陷入局部最优

3. **动作空间未充分利用**：
   - 8个移动方向 + 2个技能 = 10维动作
   - 但游戏地图有障碍，很多方向无效
   - 模型需要学习避开障碍，浪费大量探索预算

### 影响
- **样本效率极低**：需要数百万步才能学会基本策略
- **早期能力不足**：前100k步基本在随机游走
- **难以发现宝箱**：探索策略与目标不匹配

---

## 问题4：特征设计缺陷

### 现象
模型无法准确判断宝箱和怪物的相对位置关系。

### 根本原因
**特征编码存在信息损失：**

1. **距离归一化过度**：
   ```python
   dist_norm = (dist - 0) / (MAP_SIZE * 1.41)  # 0~1
   
   # 问题：128×128地图，对角线181格
   # 归一化后，1格距离 ≈ 0.0055，精度损失严重
   # 实际游戏中，1-3格距离才是关键区域
   ```

2. **方向编码不完整**：
   ```python
   # 当前：sin/cos编码
   dir_sin = (sin(angle) + 1) * 0.5  # [0, 1]
   dir_cos = (cos(angle) + 1) * 0.5  # [0, 1]
   
   # 问题：地图有障碍，直线方向≠可行路径
   # 模型需要学习导航，但特征未提供路径信息
   ```

3. **时序信息缺失**：
   - 当前特征：单帧状态
   - 缺失：怪物移动趋势、路径规划、历史轨迹
   - 结果：模型只能做短期反应，无法规划

### 影响
- **决策质量低**：基于不完整信息做判断
- **需要更多参数**：网络需要学习从归一化数据恢复原始信息
- **收敛慢**：特征学习负担重

---

## 问题5：训练架构问题

### 现象
训练前期效果差，后期提升停滞。

### 根本原因

1. **预热不足**：
   ```python
   LEARNING_STARTS = 4000  # 4局数据
   
   # 问题：SAC需要多样性样本
   # 4局数据不足以覆盖状态空间
   # PER在早期样本不足时效果差
   ```

2. **更新次数不合理**：
   ```python
   n_updates = len(list_sample_data) * (1 + buf_fill_ratio)
   # 约100~200次/局
   
   # 问题：
   # - 早期buffer小，更新少，学习慢
   # - 后期buffer满，更新多，但样本重复利用率低
   ```

3. **学习率衰减过早**：
   ```python
   LR_DECAY_STEPS = 100_000
   # 100k步后学习率衰减至终值
   
   # 问题：游戏复杂，100k步还在探索期
   # 学习率衰减→探索能力下降→陷入次优
   ```

### 影响
- **早期学习慢**：前50k步基本无进展
- **后期停滞**：学习率衰减后无法突破瓶颈
- **样本浪费**：PER在早期效果差

## 解决方案优先级

| 优先级 | 问题 | 解决方案 | 预期效果 |
|--------|------|---------|----------|
| P0 | 奖励尺度失衡 | 简化奖励设计，放大关键信号 | 收敛速度提升3-5倍 |
| P0 | 奖励噪声过大 | 移除冗余奖励，仅保留核心项 | 训练稳定性大幅提升 |
| P1 | 探索策略失效 | 调整熵目标，引入好奇心驱动 | 样本效率提升50%+ |
| P1 | 特征设计缺陷 | 增强关键特征，引入时序信息 | 决策质量提升 |
| P2 | 训练架构问题 | 调整超参数，优化更新策略 | 整体性能提升 |

## 结论

当前算法的最大问题是**奖励设计**，其次是**探索策略**。这两个问题导致：
1. 模型优化错误的目标（刷接近奖励而非收集宝箱）
2. 训练信号被噪声淹没（无法区分有效信号）
3. 探索效率极低（大量样本浪费在无效动作）

**必须立即修复P0级问题，否则任何其他优化都无法发挥作用。**

# 峡谷追猎 PPO 算法实现

## 项目简介

本项目实现了基于PPO（Proximal Policy Optimization）算法的峡谷追猎游戏AI智能体。该智能体需要在充满怪物的峡谷中生存尽可能长的时间，通过学习和优化策略来躲避怪物追击。

## 算法架构

### 核心组件

1. **模型架构** (`model/model.py`)
   - 共享MLP骨干网络 + Actor/Critic双头结构
   - 输入维度：40维特征向量
   - 输出维度：8个动作的概率分布 + 1个价值估计

2. **算法实现** (`algorithm/algorithm.py`)
   - 标准PPO算法实现
   - 包含策略损失、价值损失和熵正则化
   - 使用GAE（Generalized Advantage Estimation）计算优势函数

3. **特征工程** (`feature/preprocessor.py`)
   - 英雄自身特征（位置、闪现冷却、buff状态）
   - 怪物特征（位置、速度、距离）
   - 局部地图特征（4x4网格）
   - 合法动作掩码
   - 进度特征（当前步数、生存比例）

4. **奖励设计**
   - 基础生存奖励：每步+0.01
   - 距离塑形奖励：鼓励远离怪物

## 安装与使用

### 环境要求

- Python 3.7+

- NumPy

```bash
python train_test.py --train

python train_test.py --evaluate
```

## 算法优化方向

### 1. 网络架构优化

**当前实现**：简单的MLP结构
**优化建议**：
- 引入残差连接和层归一化，提高训练稳定性
- 使用更先进的激活函数（如Swish、GELU）
- 考虑使用注意力机制处理怪物间的相对关系
- 实现多尺度特征提取网络

### 2. 训练稳定性优化

**当前实现**：固定学习率和熵系数
**优化建议**：
- 实现学习率调度器（Cosine Annealing、Warmup）
- 动态调整熵系数，平衡探索与利用
- 添加权重衰减正则化防止过拟合
- 实现梯度裁剪的动态调整策略

### 3. 探索策略优化

**当前实现**：固定熵正则化
**优化建议**：
- 实现自适应熵系数调整
- 添加Noisy Networks增加参数噪声探索
- 实现基于不确定性的探索策略（如UCB）
- 引入好奇心驱动的内在奖励

### 4. 特征工程优化

**当前实现**：基础手工特征
**优化建议**：
- 添加相对速度、加速度等动态特征
- 实现怪物轨迹预测特征
- 添加碰撞风险预测特征
- 实现特征标准化和动态归一化

### 5. 奖励设计优化

**当前实现**：简单生存奖励+距离塑形
**优化建议**：
- 实现基于风险的复合奖励函数
- 添加阶段性奖励（如存活100步、200步等里程碑）
- 实现自适应奖励缩放机制
- 引入对抗性奖励设计，鼓励更复杂的策略

### 6. 算法层面优化

**当前实现**：标准PPO
**优化建议**：
- 实现PPO-Clip的改进版本（如PPO-Penalty）
- 添加GAE的λ参数自适应调整
- 实现多步回报（n-step returns）
- 引入经验回放机制

## 配置参数

主要超参数位于`conf/conf.py`：
- `GAMMA`: 折扣因子 (0.99)
- `LAMDA`: GAE参数 (0.95)
- `INIT_LEARNING_RATE_START`: 初始学习率 (0.0003)
- `CLIP_PARAM`: PPO裁剪参数 (0.2)
- `VF_COEF`: 价值损失系数 (1.0)
- `BETA_START`: 熵系数 (0.001)

## 性能指标

监控指标包括：
- 总损失（total_loss）
- 策略损失（policy_loss）
- 价值损失（value_loss）
- 熵损失（entropy_loss）
- 平均奖励（reward）
